# Santhiya's Portfolio Showcase

Build a **premium, professional, modern personal portfolio website** for **Santhiya Sree S**, an MCA student and aspiring IT professional.

Act as an **experienced senior UI/UX designer and frontend product designer**. The portfolio should not look like a generic student template. Create a design that feels **clean, elegant, minimal, modern, aesthetically refined, and professional enough to impress recruiters and IT companies**.

## IMPORTANT DESIGN DIRECTION

* Use a **light theme as the primary design**.
* Avoid black or overly dark full-page backgrounds.
* Use a sophisticated color palette based on **soft white, very light blue, subtle lavender, and muted indigo/blue accents**.
* The overall UI should feel premium and polished, similar to a modern SaaS/product designer portfolio.
* Use plenty of whitespace and strong visual hierarchy.
* Use rounded cards with subtle shadows and thin borders.
* Add smooth gradients only where they improve visual appeal; do not overuse them.
* Typography should be modern, highly readable, and professional.
* Use subtle micro-interactions, hover effects, smooth scrolling, fade-in animations, and gentle transitions.
* The design must be fully responsive for desktop, tablet, and mobile.
* Do not make the website look crowded.
* Keep all information easy to scan for recruiters.
